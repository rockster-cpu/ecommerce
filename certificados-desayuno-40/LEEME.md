# Reconocimientos – Desayuno Empresarial con Propósito #40

- `Reconocimientos_Ponentes_Desayuno40.pdf`: las 3 ponentes (una hoja cada una), listo para imprimir.
- `Reconocimiento_<Nombre>.pdf`: un PDF por ponente.
- `Reconocimiento_EN_BLANCO.pdf`: mismo diseño sin nombre, por si se necesita uno extra.

Impresión: tamaño **Carta**, orientación **horizontal**, escala **100 % / tamaño real**.

## Cambiar nombres
1. Edita la lista `NOMBRES` al inicio de `certificado.html`.
2. Ábrelo en Chrome → Imprimir → Guardar como PDF (Carta, horizontal, márgenes "Ninguno", activar "Gráficos de fondo").
   O bien, con Node + Playwright: `node generar.js` (edita la lista `archivos` en ese script).
