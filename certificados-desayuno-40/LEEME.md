# Reconocimientos – Desayuno Empresarial con Propósito #40

Diseño elegido: **moderno** (`certificado-moderno.html`), con el logo original de Oleda,
el círculo del logo como marca de agua, el código EC0217.01 y solo la firma de Oleda Maldonado.

- `Moderno_TODAS.pdf`: las 3 ponentes, una hoja cada una.
- `Moderno_<Nombre>.pdf`: un PDF por ponente, y `Moderno_EN_BLANCO.pdf` sin nombre.

Impresión: tamaño **Carta**, orientación **horizontal**, escala **100 % / tamaño real**.
El panel azul llega hasta la orilla: en imprenta pide impresión "a sangre / sin bordes"
para que no quede una franja blanca.

## Cambiar nombres
1. Edita la lista en `nombres.js`.
2. Abre `certificado-moderno.html` en Chrome → Imprimir → Guardar como PDF
   (Carta, horizontal, márgenes "Ninguno", activar "Gráficos de fondo").
   O con Node + Playwright: `node generar.js certificado-moderno.html Moderno`.

(`certificado.html` es la opción clásica, por si se quiere usar después.)
